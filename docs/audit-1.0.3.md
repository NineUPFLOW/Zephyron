## Список C — не сделано

- **DNSCrypt, анонимный DNSCrypt, ODoH:** нужен отдельный движок dnscrypt-proxy. Шифрование DoH уже есть, новый бинарник не добавлен.
- **Zapret DNS:** его DoH не проверен.
- **01bc083 (окно рецептов считает ответы с ошибкой):** другая механика, требуется отдельная оценка.
- **Мягкая остановка sing-box из CLI:** там остаётся Kill.
- **Подпись обновлений:** SHA-256 берётся из того же API GitHub, это защита от порчи, а не доказательство подлинности.
- **Полный редизайн, исследование 12 проектов из задания, разделение прав:** не выполнены. Сравнение сделано только с NetZapret. Приложение по-прежнему целиком требует администратора.
