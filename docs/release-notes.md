# Что нового

## Маршруты

### Новое:

**Автоподбор маршрутов.** Кнопка «Автоподбор» в «Маршрутах» сама проверяет каждый сервис и ваши маршруты и подбирает, как их открывать: напрямую, десинком пресета, своим рецептом, пином в hosts или через VPN. VPN — только если иначе никак: что открывается без него, уходит с VPN и экономит его трафик.

**Подбор для одного сайта.** Вставьте ссылку или домен — подбор пройдёт только для него. Сайт из известного сервиса получает маршрут сервиса, без дубля.

**Честная проверка.** Отказ по стране («Not Available», перенаправление на «недоступно в регионе») не считается открытым сайтом, проверка Cloudflare на робота — не считается отказом. Каждое решение подтверждается вторым замером. Голос и служебные адреса помечаются «не сайт» и не трогаются.

**Всё можно вернуть.** «Вернуть» у строки или «Вернуть всё»; после записи и отката движки перезапускаются сами, записанное сразу проверяется. Журнал каждого прогона — в папке reports.

**Учитывает ваши настройки.** Выключенные части, свои правила на имя, game filter и перехват со страницы «Десинк», выбранный пресет и выбранный сервер VPN.
