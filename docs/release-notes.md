# Что нового

## VPN

**WARP работает без подписки.** Включили переключатель — и бесплатный выход Cloudflare подключается сам, даже там, где провайдер закрыл обычные адреса регистрации.

**Страна выхода WARP.** Если есть подписка, WARP можно вывести в стране её сервера: сайты, закрытые для России, увидят другую страну. Программа сама проверяет, какая страна получилась.

**Кнопка «Добавить файл WARP»:** готовый файл AmneziaWG с warp-generation.github.io добавляется как обычный сервер.

## Десинк

**«Подобрать под мою сеть»** прямо на странице: программа проверит сервисы и подберёт для каждого рабочий способ.

**Результат подбора можно сохранить как свой пресет** — включить его, передать или взять на другой компьютер.

## Интерфейс

**Понятнее и единообразнее:** у пресетов «Выбрать» вместо «Включить», одинаковые названия настроек во всех окнах, предупреждение, если включено «Без исключений», подсказка «Осталось нажать «Включить»» после мастера.

**Меньше дублей:** «Сайт не открывается?» ведёт в «Проверку блокировок», лишняя «Диагностика» убрана с Главной.
