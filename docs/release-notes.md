# Что нового

## Маршруты

**Путь сразу для всего сервиса.** У сервиса из нескольких частей (у Discord их восемь) в «Маршрутах» есть кнопка, которая ставит один путь всем частям сразу. На ней виден текущий путь или «разные», если у частей он не совпадает.

## Discord

**Голосовые каналы на Strict.** На Strict Discord открывался, но голос у части провайдеров не подключался. Теперь голосовые серверы идут через обход так же, как на Adaptive.

## Исправлено

**Adaptive снова открывает YouTube.** Если программа однажды переключила YouTube на запасной способ обхода, она могла остаться на нём, даже когда он перестал работать. Теперь через 12 часов она снова начинает с основного способа.

**Проверка блокировок показывает сервер по названию.** Перед названием сервера выводилась лишняя буква вместо флага.
