# Что нового

## YouTube

**Видео надёжнее.** Браузер сразу идёт проверенным путём и не ждёт зависшего соединения.

**Запасной профиль для серверов видео** срабатывает по адресу, если имя сервера не распозналось.

## Проверка блокировок

**Поле «сайт или адрес» прямо на странице:** вставьте адрес и нажмите Enter.

**Проверка стала быстрее,** а серверы видео теперь меряются настоящим объёмом данных.

**Видно нейросети, закрытые по стране,** и когда режут длинное приветствие.

## Пины

**Zephyron сам следит за пинами** и заменяет мёртвые адреса. При сбое сети hosts не меняется.

## VPN

**Поддержка AmneziaWG 3.**

**Ключи больше не попадают в журналы.**

## Discord и DNS

**Отдельный маршрут «Квесты и API»** для Discord.

**Новый сервер Zapret DNS** и свежий каталог адресов.

## Интерфейс
