# Что нового

## Туннель — только когда иначе никак

**Сначала обход, потом выход за границу.** Автоподбор пробует по порядку: напрямую → десинк → рецепты → пин в hosts, и только если ничего не помогло — туннель: VPN, а у кого подписки нет — WARP. Выход за границу включён как последний шаг по умолчанию; выключить можно в окне автоподбора.

**WARP — замена VPN для тех, у кого нет подписки.** Есть подписка — туннель идёт через её серверы; нет — через встроенный WARP.

**Найденный способ проверяется трижды.** Автоподбор записывает путь, только если он сработал три раза подряд, и проверяет все адреса сайта: если у сайта часть адресов закрыта, такой путь не считается рабочим.

## Окно автоподбора понятнее

- С первой секунды видно, что идёт: «Узнаю адреса имён…».
- Если менять нечего, так и написано, а главная кнопка — «Готово».
- После записи у каждой строки видно, открылась ли она, и что не открылось — можно вернуть.

## Для новых пользователей

Сразу «Гибрид»: десинк для всего, что он чинит, туннель — только маршрутам, закрытым по адресу или по стране. Без подписки туннель идёт через встроенный WARP, Telegram — через свой прокси. Маршруты по умолчанию: сайт и веб-версия Telegram и Crunchyroll — через туннель, RuTracker — десинком.

## DNS

В режиме «Десинк» с DNS «авто» программа при запуске проверяет DNS оператора: если он прячет YouTube и другие сайты, запросы сами идут через DoH.

## Локальный прокси

Карточка на вкладке VPN: `127.0.0.1:2080` (SOCKS5 и HTTP) для отдельных программ — браузера, Telegram, лаунчера. Если прокси не поднялся (порт занят, нет серверов), карточка говорит почему.

## Проверка и диагностика

- Капча и «проверка браузера» больше не считаются «доступен».
- «Наблюдение» и «Диагностика» показывают имена, которые идут мимо туннеля из-за стороннего DNS.

## Надёжность

- Испорченный файл настроек сохраняется в копию, а не теряется; запись настроек не мешает сама себе.
- Обновление больше не пропускает одноимённые файлы в разных папках.
- Свои списки нельзя направить за пределы своей папки.
- Кнопки не молчат: при ошибке видно, что случилось.
- Окна помещаются на небольших экранах.
