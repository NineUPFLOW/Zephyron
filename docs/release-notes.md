# Что нового

## DNS

**Больше резолверов.** Добавлены DNSPod (Tencent), Wikimedia DNS, Digitale Gesellschaft, UncensoredDNS, Applied Privacy, RESTENA и CIRA Canadian Shield — все проверены по DoH из России.

**Автоподбор DNS не берёт подменяемый резолвер.** Если провайдер подменяет ответы резолвера, автоподбор выбирает следующий чистый, а не самый быстрый любой — «Диагностика» больше не ругается на только что выбранный DNS.

## Маршруты

**LinkedIn без спора правил.** Заводской путь LinkedIn теперь задан списком сервиса: свой путь из «Маршрутов» заменяет его, и «Диагностика» не показывает перекрытие.
