# Что нового

## Маршруты

### Новое:

**Проверка папки автоподбором.** В меню «…» у сервиса или папки — «Проверить автоподбором»: подбор идёт сразу по всем её маршрутам, как «Автоподбор» сверху, только для этих имён. У Discord, например, семь маршрутов — руками их не перебрать.

## Главная

### Исправления:

**Дорожки бегут плавно.** Скорость меняется вслед за трафиком постепенно, за секунду, а не скачком на каждом замере.

**«Главная» больше не растёт.** Карточка событий — не выше четырёх строк, остальные в «Весь журнал». Предупреждения — одной строкой, полный текст в подсказке. Низ страницы больше не уходит за край.

## Оформление

### Новое:

**В редакторе темы сказано, что фоном можно поставить видео** — MP4, крутится по кругу без звука. Выбирается той же кнопкой, что и картинка.
