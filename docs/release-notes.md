# Что нового

## YouTube

**Редкие ролики грузятся без VPN.** Узлы Google, с которых идут ролики с небольшим числом просмотров, провайдер режет: ответ сервера до вас не доходит. Теперь такой узел получает малое окно приёма в начале соединения: сервер дробит ответ, и фильтр его не узнаёт. Видео идёт без туннеля, сам ничего настраивать не нужно.

**Старт ролика быстрее.** Сторож проверяет узлы раз в 3 секунды, помнит починенные сети неделю и знает узлы под вторым именем (`*.c.youtube.com`), на которых плеер проверяет связь перед видео.

**hosts не засоряется.** Узлы под окном пишутся в отдельный список движка, сетями. В hosts попадает только узел, который не ожил и под окном, и таких записей не больше 32.

## Главная

**«События» понятным языком:** «Десинк: работает», «Туннель (VPN): работает», «YouTube: починены узлы видео». Служебные строки остались в «Весь журнал».
