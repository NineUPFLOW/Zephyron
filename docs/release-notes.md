# Что нового

## VPN

### Новое:

**Kill switch** — выключатель на вкладке VPN, для режима «Туннель». Пока туннель не работает — упал, перезапускается или ждёт сервера, — мимо него с вашего адреса не уходит ничего: в сеть выходят только сам движок, Zephyron и локальная сеть (роутер, принтеры, Radmin и Hamachi). Новый адаптер — второй Wi-Fi, телефон по USB — закрывается, как только появится. Остановили движки или закрыли программу — Windows снимает фильтры сама, сеть закрытой не остаётся. Если рядом работает другой обход на WinDivert, kill switch не включается и говорит почему. По умолчанию выключен.

**Ключи AmneziaVPN `vpn://`** вставляются в окно добавления как есть — то, что выдаёт «Поделиться» в AmneziaVPN, без выгрузки файла .conf.

**Описание сервера от панели — строкой под именем,** а не хвостом `?serverDescription=…` в самом имени.

### Исправления:

**Один кривой сервер больше не роняет туннель.** Если движок отказывается подняться из-за одного сервера подписки — незнакомая настройка, битый ключ, испорченный путь, — программа сама убирает этот сервер из конфига и поднимает туннель на остальных. В журнале туннеля видно, какой сервер убран и почему.

**Подписки с `flow: xtls-rprx-vision-udp443` работают.** Такой flow понимается как обычный Vision — раньше один такой сервер не давал туннелю подняться вовсе, помогало только отключить подписку.

**Серверы REALITY с пустым или испорченным ключом и серверы с битым %-кодом в пути** пропускаются сразу, при разборе подписки.

**Ключ Outline с косой чертой после порта** (`…:8388/?outline=1`) теперь добавляется.

**Туннель поднимается, когда IPv6 выключен в Windows** через реестр, — раньше движок падал при запуске: «set ipv6 address: Element not found».

**Подписка, панель которой не ответила через туннель, спрашивается мимо него** — туннель на устаревшем сервере больше не мешает ей обновиться. С включённым kill switch мимо туннеля не ходит и подписка.

## TG Proxy

### Новое:

**Свой воркер Cloudflare.** Общие домены Cloudflare упираются в ограничения и отвечают 503 — Telegram подключается через раз. В строке «Свой воркер Cloudflare» можно указать свой воркер, кнопка «Скопировать код» даёт готовый код для него; прокси пробует воркер раньше общих доменов. Воркер пускает только к адресам Telegram, открытым прокси для чужих он не станет.

## Проверка блокировок

### Новое:

**Чем именно режут.** Закрытое рукопожатие проверка повторяет с чужим именем на тот же адрес: прошло — режут имя, и поможет десинк; не прошло ни с каким — режут адрес, нужен VPN; прошло только с разрешённым именем — пропускают лишь белый список, и нужен рецепт с подделкой разрешённого имени.

**QUIC.** У открытых сайтов, объявляющих HTTP/3, проверяется и QUIC. Молчит — в подробностях «QUIC молчит, а TCP работает»: браузер ждёт HTTP/3 и подвисает, хотя по TCP всё открывается.

### Исправления:

**«Отказывает по стране» — только когда сайт сам называет страну или регион.** Ответ 403 без объяснений — «сайт отказал, причину не назвал» с советом проверить в браузере.

**Имя, у которого в DNS только домашний адрес,** — «нет адреса у имени», а не «туннель не доставил» с советом сменить сервер.

## Десинк

### Новое:

**winws2 обновлён до v1.0.6-33** — свежая родная сборка движка десинка без Cygwin.

## Оформление

### Новое:

**«Работает» и рамка окна Windows — свои цвета в редакторе тем.** Раньше слот «Работает» на деле был акцентом: он же красил рамку окна, а настоящие зелёные точки и линии оставались зелёными при любом выборе. Старые темы получают новые цвета сами.

**Светлые темы с мягкой тенью под карточками** — карточка больше не теряется на светлом фоне.

## Общее

### Исправления:

**Обновление не срывается, если антивирус отпустил архив в ту же секунду,** когда программа проверяла, занят ли он.

**В отчёте — серверы подписок и причина, если сервер отброшен,** номерами, без имён, адресов и ключей.
