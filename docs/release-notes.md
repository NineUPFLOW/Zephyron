# Что нового

## YouTube

**Видео YouTube грузится без VPN, даже когда узел видео под фильтром.** С конца октября часть серверов Google, с которых идёт видео, фильтр режет по адресу, а кэш Google у провайдера бывает сломан сам (Ростелеком, ТТК). Десинк тут бессилен, и плеер застывал. Теперь Zephyron, пока работают движки, раз в 20 секунд проверяет узлы, к которым ходил браузер, тем же путём, что и браузер. Нерабочий узел он отключает записью в hosts, и плеер в ту же секунду берёт другой. Через полчаса узел проверяется снова, через 12 часов запись снимается. Ничего вставлять и искать не нужно.

**Работает сам и включён по умолчанию.** Выключатель — «Маршруты» → «Параметры» → «YouTube». Браузер должен брать адреса у Windows: встроенный DNS-over-HTTPS (в Firefox включён по умолчанию) обходит hosts.
