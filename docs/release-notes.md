# Что нового

## YouTube

**Новый пресет по умолчанию — Zephyron Adaptive.** Открывает всё то же, что Universal V12 Lite, а если провайдер начинает резать YouTube — страницу, превью или само видео, — программа сама переключается на другой способ обхода. Нажали «Включить» — и всё.

**Видео не подвисает на старте.** Браузер больше не ждёт по 20–30 секунд, пока провайдер молча глушит быстрый протокол YouTube: сразу идёт обычным путём.

**Больше адресов YouTube и Discord** в списках обхода.

## Пресеты

**Свой пресет — отдельно.** На вкладке «Десинк» наш пресет стоит первым, пресеты Universal — своей группой с автором.

**Пресет «Ростелеком».** Для тех, у кого провайдер — Ростелеком.

## VPN

**Туннель не душит десинк на больших подписках.** Из-под десинка выводятся адреса 40 серверов, а при подписке на сотни серверов это были первые 40 по списку — автовыбор же брал самый быстрый из всех, и его соединения десинк продолжал трогать: туннель сыпал таймаутами. Теперь первыми защищаются самые быстрые по замерам.

## Отчёт

**Проверка блокировок не путает состояние.** Если обход только что включили, отчёт больше не пишет «движки остановлены».

**YouTube в отчёте — тем путём, каким он идёт сейчас.** Если движки работают, отчёт проверяет страницу, миниатюры, аватары, API и раздатчик видео YouTube и пишет, что из этого не открывается.

**Ещё пояснения в сводке ошибок.** Сервер VPN не успел соединиться, сервер за Cloudflare лежит, поток через сервер оборвался — теперь сказано словами, что делать.

## Автоподбор

**Не выглядит зависшим.** После проверки путей подбор ещё минуту перепроверяет найденное — теперь окно так и пишет, а не стоит на «vpn».
