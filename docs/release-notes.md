## Маршруты

### Новое:

**Автоподбор у каждого маршрута** — кнопка прямо в строке: подбор только для этого маршрута, теми же этапами, что «Автоподбор» сверху — напрямую, десинк, рецепты, пин в hosts и только потом VPN.

**Каждый сервис разворачивается** — и с одним маршрутом: у всех есть шапка, сворачиваются одинаково.
