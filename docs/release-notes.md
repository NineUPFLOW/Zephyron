# Что нового

## Десинк

### Новое:

**Пресет можно дублировать и переименовать** из меню «⋯». Пресеты поставки не переименовываются, их копии — ваши.

**Подделки секций — выбором.** Кнопка «Подделки секций…» открывает окно с поиском по имени, спискам и фильтрам; файл пресета править не нужно. Выбор действует и на запуск, и на автоподбор.

### Исправления:

**Выключенная часть по адресам гасит и секцию пресета.** Запасной путь Discord остаётся на десинке, пока его не выключить руками.

**Код winws2 FWP_E_IN_USE объяснён** на «Главной». Выгрузка драйвера не трогает чужой WinDivert.

## VPN

### Новое:

**Запас подписки виден сразу**, разные панели читаются одновременно. Копия сервера под другим именем помечена «копия».

**Новые транспорты и шифрование:** mKCP, VLESS Encryption, ранние данные WebSocket. Незнакомый транспорт больше не считается TCP — сервер пропускается с причиной.

### Исправления:

**Туннель поднимается и без IPv6 в Windows.** WireGuard и AmneziaWG открывают сокет одного семейства. Маскировка AmneziaWG, которой движок не знает, больше не теряется молча. Ошибка ключа `vpn://` называет шаг, на котором разбор не удался.

**sing-box останавливается штатно**, и память подставных адресов переживает перезапуск.

## DNS

**Резолверы разбиты на разделы:** посредники, популярные, без фильтрации, с фильтрацией, свои. Метки «блокируется» и «UDP подменяют» ставятся по вашему замеру. Добавлены AdGuard Семейный и ControlD без рекламы.

## Маршруты

**Набор `.zyroutes`:** файл с маршрутами теперь везёт и ваши списки. У получателя существующие списки не перезаписываются.

## Проверка блокировок

**Отказ сайта — не блокировка.** Голый 403 показывается отдельно, страна называется только если её назвал сам сайт. Чужой сертификат, частный адрес и заморозка на 26–28 КБ различаются точнее.

## Обновление и запуск

**Архив обновления сверяется по SHA-256** из данных выпуска на GitHub. Если надзор умер сразу после старта, запуск честно сообщает об отказе.
