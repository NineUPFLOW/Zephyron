# Что нового

## VPN

**Свой файл WARP — прямо в карточку WARP.** Кнопка «Загрузить файл WARP» открывает выбор файла `.conf` (AmneziaWG с warp-generation.github.io): WARP включается и идёт через ваш файл вместо встроенного подключения. «Вернуть встроенный» — обратно.

**Добавленный сервер работает сразу.** Если был включён встроенный WARP, он выключается сам, и туннель идёт через добавленное.

**Страница VPN честнее:** у приостановленных подписок написано «На паузе», без подписок нет ложных «подписки приостановлены» и «VPN недоступен», при WARP не показывается выбор серверов, которым нечего выбирать.

Если раньше вы добавили файл WARP как ключ в «Отдельные ключи» — удалите его оттуда и загрузите в карточку WARP.
