# Что нового

## YouTube

**Узлы видео под фильтром — без потери скорости.** Малое окно приёма теперь получает только адрес, на котором ответ уже срезали: на минуту, а если срезали снова — на час. Остальные узлы и кэш провайдера идут на полной скорости. В 1.4.5 окно доставалось целым сетям, и часть роликов грузилась медленно.

**Работает и со своим рецептом для googlevideo.** Если в «Маршрутах» для видео выбран свой рецепт, малое окно больше не теряется.

## Telegram

**Мосты подбираются сами.** Автоподбор включён по умолчанию: без него прокси ходил одним общим доменом, а тот часто отвечает 503. На подбор теперь есть 20 секунд вместо 8, раньше он обрывался и не сохранялся.

## Исправлено

**Отключённый узел видео терял десинк.** Узел с записью сторожа в hosts попадал в список «десинк не трогать» и ожить уже не мог.

**Утечка памяти «Главной».** Закрытая «Главная» держалась в памяти, пока дочитывался журнал «Событий».
