# Что нового

## YouTube

**Новый пресет по умолчанию — Zephyron Adaptive.** Открывает всё то же, что Universal V12 Lite, а если провайдер начинает резать YouTube — страницу, превью или само видео, — программа сама переключается на другой способ обхода. Нажали «Включить» — и всё.

**Если не помогло ничего — Zephyron Strict.** Когда ни один способ в Adaptive не открыл YouTube, программа сама включает пресет для строгих провайдеров. Вернуть прежний можно на вкладке «Десинк».

**Видео не подвисает на старте.** Браузер больше не ждёт по 20–30 секунд, пока провайдер молча глушит быстрый протокол YouTube: сразу идёт обычным путём.

**Проверяется ваш видеосервер.** Программа узнаёт, с какого сервера YouTube вам идёт видео, и следит именно за ним.

**Больше адресов YouTube и Discord** в списках обхода.

## Пресеты

**Пресеты Zephyron — отдельной группой.** На вкладке «Десинк» наши пресеты стоят первыми, пресеты Universal — своей группой с автором.

**Zephyron Strict.** Для провайдеров, которые режут строже обычного, например Ростелеком.

**Без лишних подписей.** У пресетов больше нет непонятных номеров версий, а блок «Какой трафик перехватывать» не вываливает список портов: если что-то не получит трафик, сказано одной строкой.

## Проверка блокировок

**Сразу видно проблемы.** По умолчанию показаны только сайты, с которыми что-то не так; все остальные — по кнопке «доступен».

**«С прошлой проверки» — коротко.** Вместо простыни «было — стало» по каждому сайту: что открылось и что перестало открываться.

**Без ложных советов.** У открывающихся сайтов больше нет совета «выключите QUIC в браузере», а проверка с включённым обходом не выглядит как предупреждение.

**Не путает состояние.** Если обход только что включили, отчёт больше не пишет «движки остановлены».

## Журнал

**Без стены ошибок.** Одинаковые строки подряд сворачиваются в одну с числом повторов, служебный шум скрыт, у строк туннеля есть время.

**События на «Главной» — только важное.** Уборка старых замеров и служебные строки запуска туда больше не попадают.

## Маршруты

**Маршрут не теряет рецепт при смене пресета.** Рецепт, выбранный по секции другого пресета, берётся из Zephyron Adaptive, а не пропадает.

## VPN

**Туннель не душит десинк на больших подписках.** Первыми из-под десинка выводятся самые быстрые серверы — тот, что выбран автоматически, больше не сыплет таймаутами.

## Отчёт

**YouTube в отчёте — тем путём, каким он идёт сейчас.** Страница, миниатюры, аватары, API и ваш видеосервер; ваш IP в отчёт не попадает.

**Ещё пояснения в сводке ошибок.** Сервер VPN не успел соединиться, сервер за Cloudflare лежит, поток через сервер оборвался — теперь сказано словами, что делать.

## Автоподбор

**Не выглядит зависшим.** После проверки путей подбор ещё минуту перепроверяет найденное — теперь окно так и пишет.
