# Что нового

**Окно разворачивается на весь экран.** В 1.4.0 высота окна была ограничена, и развёрнутое окно не занимало экран целиком.

**Локальный прокси убран.** Карточки на вкладке VPN и настройки в «Параметрах туннеля» больше нет: функция нужна была немногим и только мешала.

**Проверка обновлений не упирается в лимит GitHub.** Если GitHub отказывает в запросе (лимит на адрес, частый у мобильных операторов), версия берётся со страницы выпуска.
