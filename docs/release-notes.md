# Что нового

## Интерфейс

**В подписях вернулись значения:** номер шага в мастере, число серверов, путь к отчёту, имя пресета и другие.

## Обновление и запуск

**Движки поднимаются сами после обновления,** если работали до него. Начнёт действовать со следующего обновления: после установки 1.1.1 включите движки на «Главной».
