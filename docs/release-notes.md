# Что нового

## VPN и WARP

**Туннель идёт через VPN или WARP — выбираете сами.** Наверху вкладки VPN переключатель «Туннель идёт через»: «VPN» — ваши подписки и ключи, «WARP» — бесплатный выход Cloudflare. Маршруты «через VPN» идут выбранным путём. Режимы «Десинк», «Туннель» и «Гибрид» остались на месте.

**WARP работает без подписки.** Ни ключей, ни почты: учётную запись движок заводит себе сам. Свой файл WARP (`.conf` AmneziaWG) загружается в карточку WARP, «Вернуть встроенный» — обратно.

**Вкладка VPN — одной колонкой, без пустот.** Невыбранный путь свёрнут, у кнопок понятные названия: «Выбрать», «Выбран», «Замерить WARP».

## Автоподбор

**Выход за границу — только с вашего разрешения.** Автоподбор пробует напрямую, десинк (пресет и рецепты) и пин в hosts; VPN или WARP — только если иначе никак и включён переключатель «Разрешить выход за границу, если иначе никак». По умолчанию он выключен.

## DNS и пины

**Два новых посредника для пинов:** WLRUS DNS и Dagami DNS — через них открываются ChatGPT и Gemini.

## Telegram

**«Подключить Telegram» работает и с переносным Telegram.** Ссылка прокси передаётся прямо в запущенный Telegram, даже если Windows помнит его старое место. Telegram не запущен и не найден — ссылка копируется, программа говорит, что делать.

**Страница TG Proxy больше не закрывает программу**, если файл маршрутов не читается.

## Кнопки

Кнопки больше не молчат и не обещают лишнего: неудачный запуск из трея показывает причину, «Остановить» сообщает о невыгруженном драйвере, «Запомнить» и «Скопировать код» у воркера отвечают, не открылся браузер — ссылка копируется. Автоподбор, пины, сброс настроек, уборка, сброс сети и мастер первого запуска пишут честный итог, а при ошибке не оставляют программу в половинчатом состоянии.
