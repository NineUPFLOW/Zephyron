# Как помочь проекту

Код здесь не главное. Полезно и другое.

## Сообщить о поломке

Самое полезное. Откройте [issue](https://github.com/NineUPFLOW/Zephyron/issues/new/choose)
и выберите шаблон:

- **«Сервис не работает»** — что-то не открывается;
- **«Ошибка в программе»** — падает, не запускается или ведёт себя не так,
  как написано.

Шаблоны спрашивают то, без чего разбор не начать: вывод проверки блокировок,
режим, пресет, оператора. Пустой issue закрыт специально.

**Не присылайте ссылку на подписку**, `config\subscriptions.json` и содержимое
`runtime\`: там ключи серверов. Подробнее — в [SECURITY.md](SECURITY.md).

Вопросы и идеи — в [обсуждениях](https://github.com/NineUPFLOW/Zephyron/discussions).

## Прислать тему оформления

Тема — папка с `theme.json`, картинкой фона и, при необходимости, шрифтом.
Формат описан в [themes/README.md](themes/README.md). Собрать тему можно в самой
программе: «Оформление» → «Создать тему». «Выгрузить в файл…» упакует её.

Картинка и шрифт должны быть ваши или с лицензией, которая разрешает
распространение. Программа покажет нечитаемые сочетания цветов и предложит
поправить.

## Прислать код

Как собрать проект — в разделе [«Сборка из исходников»](README.md#сборка-из-исходников).

Перед запросом на слияние:

- проходят оба набора тестов: `dotnet test` и `dotnet test gui/Zephyron.Gui.sln`;
- сборка без предупреждений. CI собирает с `-warnaserror`, и предупреждение там
  становится ошибкой:

  ```bash
  dotnet build --configuration Release -warnaserror
  dotnet build gui/Zephyron.Gui/Zephyron.Gui.csproj --configuration Release -warnaserror
  ```

### Принципы кода

- **Логика живёт в библиотеках `src/`**, а не в окне и не в `zy`. Две копии одного
  расчёта со временем расходятся.
- **Комментарии по-русски и объясняют, почему**, а не что. У измеренного факта
  указывайте дату замера.
- **Списки только наши**, из `config/lists/`; пресеты только из `presets/`.
  Правило, которое ссылается на файл чужой установки, без неё молча не совпадёт ни с чем.
- **Файл hosts меняется** только через пины и раздел «Файл hosts», и перед каждой
  правкой делается копия. **Защитник** получает исключение только для папки
  программы и никогда не отключается.
- **Файлы `.cmd` — только ASCII и окончания строк CRLF.** С LF `cmd.exe` теряет
  метки и выполняет обрывки строк. Это проверяет тест.
- **Секции пресета с разбором внутри не переписывать**: в их комментариях лежит
  история замеров.

### Сообщение коммита

По-русски. Заголовок — что изменилось, одной строкой без точки. Дальше: что было,
почему это оказалось неверным, чем проверено, что стало. Цифры замеров приводите:
через полгода только они и останутся доказательством. Если правка закрывает
issue, напишите `Fixes #N`.

Одна мысль — один коммит.
