# Память проекта Zephyron

Ведётся мной (агентом), не владельцем. Что стоило времени — то и здесь.
Подробности по дням — в `daily/YYYY-MM-DD.md`, индекс — этот файл.

## Правила работы (жёсткие)

- **Основную ветку не трогать.** Вся работа — на ветке `tests` (или новой,
  названной владельцем). Основная — `zephyron`; в неё только по прямой просьбе
  владельца. Не релизить по своему почину.
- **Выпуск — только по «релизь X.Y.Z».** «Переименуй в X.Y.Z» — только номер.
- **Память владелец чистит сам.** Если он сказал «пиши с нуля» — старые файлы
  удалены, писать заново, а не восстанавливать.

## Проект

- Zephyron — GUI-обход блокировок для Windows: WPF-окно (`gui/Zephyron.Gui`)
  + ядро (`src/`), консоль удалена 23.09 (остался `zy` — инструмент разбора).
- Родственный репозиторий: `RixyPow/netzapret` — параллельная копия (не форк),
  NetZapret→Zephyron, `nz.cmd`→`zy.cmd`, `CLAUDE.md`→`AGENTS.md`, RixyPow→NineUPFLOW.
- Версия — `<Version>` в `Directory.Build.props`, не в cmd.
- Релиз — ручной: `.github/workflows/release.yml`, `workflow_dispatch`, ref `zephyron`.
  `build.yml` — push в main/zephyron + PR, только тесты.

## Оформление (ветка tests)

- **Источник правды — макет владельца `docs/design/mockup.html`** (1503 строки).
  Других описаний дизайна не искать и не выдумывать. Открывается в браузере.
- Сделано: плавающая таблетка навигации сверху (`TopPill`), «Главная» одной
  колонкой по центру. Макет — тёмный: подложка `#08090F`, поверхности
  `#14171F`/`#1A1E28`, линии `#21252F`, текст `#EEF1F7`/`#A8B0C2`/`#7B849B`,
  акцент `#22D3EE`, сиреневый `#A855F7`, зелёный `#10B981`, жёлтый `#FBBF24`,
  красный `#F43F5E`.
- **Слоты темы — ровно 14** (`theme.json`, чужие темы). Цвета макета сверх
  слотов (Ok, Purple, *Soft) — НЕ слоты, а выводятся в `Themes.Build`;
  в `Palette.xaml` объявлены теми же ключами (тест `ABuiltThemeHasEveryKeyOfTheXamlPalette`).
- Раздел `more` переименован «Ещё»→«Прочее» (иначе «Ещё» открывало бы меню
  с пунктом «Ещё»); прежнее имя — синоним в `NotesCategories`.
- «Главная»: герой (пилюля, крупный таймер от `StartedAt`, полоса, кнопка
  питания), метрика сети, панель режима, пары карточек, быстрые действия,
  баннер поддержки, строка внизу. Логика не тронута — только форма.

## Грабли

- **WPF на Linux не запускается**: `Zephyron.Gui.Tests` только собираются,
  testhost падает. Проверять разметку статически (regex-скрипты в daily-логе):
  ссылки `{StaticResource}` против ключей темы, токены против `docs/design-system.md`,
  «геометрический токен не несёт числа».
- **`Zephyron.Core.Tests` на Linux — 33 падения, это базовый уровень** (пути
  `C:\`, процессы, планировщик, реестр, robocopy). Не регрессия.
- **dotnet ставится вручную**: `dot.net/v1/dotnet-install.sh --channel 8.0
  --install-dir /home/openhands/dotnet`; нужен `libicu-dev`, иначе CLI падает
  на старте. После падения среды (сброс контейнера) ставить заново.
- Привязка `{Binding Имя}` без свойства НЕ падает — молчит (тест `BindingPathTests`).
- `DropShadowEffect` — в `System.Windows.Media.Effects`, не в `System.Windows.Media`.
- Один мьютекс `Local\Zephyron.Gui.interface` на сеанс Windows: при открытой
  установленной программе `build.cmd` остановит ЕЁ.
